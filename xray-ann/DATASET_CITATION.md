# Dataset citation and usage notes

## Kaggle dataset

Murtaza, Y. (2026). *Chest X-Ray Pneumonia — Balanced Dataset* (Version 1)
[Data set]. Kaggle. Retrieved November 26, 2026, from
https://www.kaggle.com/datasets/yusufmurtaza01/chest-xray-pneumonia-balanced-dataset

The Kaggle page describes 8,530 images (4,265 `NORMAL`, 4,265 `PNEUMONIA`)
from the Guangzhou Women and Children's Medical Center, balanced using
undersampling and augmentation. It requests citation of the original paper
and the Mendeley data record.

## Underlying source

Kermany, D. S., Goldbaum, M., Cai, W., Valentim, C. C. S., Liang, H.,
Baxter, S. L., McKeown, A., Yang, G., Wu, X., Yan, F., and others. (2018).
Identifying Medical Diagnoses and Treatable Diseases by Image-Based Deep
Learning. *Cell, 172*(5), 1122–1131.e9.
https://doi.org/10.1016/j.cell.2018.02.010

Mendeley Data record:
https://data.mendeley.com/datasets/rscbjbr9sj/2

## License and redistribution

Kaggle's dataset metadata labels the upload **CC0: Public Domain**, while the
dataset description says **CC BY 4.0** and asks users to cite the original
paper and Mendeley record. These statements conflict. The image files are
excluded from this repository; verify applicable rights and attribution
requirements before redistributing them.

The images are pediatric medical data. This project is educational and is
not intended for clinical or diagnostic use.
