# Dataset citation and usage notes

## Citation

Carlos, W. (n.d.). *The Simpsons (Bart and Homer) Data* (Version 2) [Image
dataset]. Kaggle. Retrieved November 26, 2026, from
https://www.kaggle.com/datasets/williamu32/dataset-bart-or-homer

Kaggle account: [williamu32](https://www.kaggle.com/williamu32). The Kaggle
dataset page lists the license as
[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
(CC BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/).
The page describes two character folders with a train/test split and states
that the images were taken and labeled from episodes of *The Simpsons*.

## Local copy

The local copy contains 269 BMP images:

- Training: 196 images (118 Bart, 78 Homer)
- Test: 73 images (42 Bart, 31 Homer)

The counts match the dataset page's description. The local files are kept in
`data/archive/dataset_personagens/dataset_personagens/`.

## Redistribution caution

The Kaggle page's license metadata is attributed to the dataset upload. The
images themselves are taken from a copyrighted television program, so that
metadata alone should not be treated as proof that the uploader could license
all underlying image rights. The image data is excluded from Git; do not
publish or redistribute it unless you have confirmed the necessary rights.
Keep this citation and the Kaggle source link with any analysis that uses the
dataset.
